# NEMA-supplementary-R-code

Supplementary material for the manuscript *Network-Embedded Mixture Analysis for Detecting Collective Effects of Correlated Micro-Effect Exposures*.

## Contents

- `Supplementary_material_NEMA_complete_R_code.R` — complete R code for the manuscript: core NEMA functions, the formal simulation study, and the NHANES POPs and leukocyte telomere length empirical analysis.

## Data availability

- **Simulated data**: generated by the deposited code using fixed random seeds documented in the script. Run `RUN_SIMULATION=TRUE` (see the header comments of the R file for all options); per-replicate random seeds are derived deterministically, so every simulated dataset can be regenerated exactly.
- **Empirical data**: publicly available, de-identified NHANES 2001–2002 data distributed by the National Center for Health Statistics, Centers for Disease Control and Prevention: https://wwwn.cdc.gov/nchs/nhanes/
- The empirical analysis uses the shared `studypop.csv` file from the public repository accompanying Gibson et al. (2019): https://github.com/lizzyagibson/SHARP.Mixtures.Workshop
